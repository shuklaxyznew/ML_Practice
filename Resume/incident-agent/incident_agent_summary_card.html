Interview Q&A — Know These Cold
Q: Why LangGraph AND CrewAI?
LangGraph = workflow engine (when, state, routing). CrewAI = collaboration engine (who, role, task). They solve different layers. LangGraph outer, CrewAI inner.
Q: How do agents share information?
Through AgentState TypedDict — shared whiteboard. Agents never call each other. Everything goes through state. In production: Redis for distributed execution.
Q: What happens when an agent hallucinates a tool?
handle_parsing_errors=True catches it, feeds error back as Observation. Agent self-corrects. Non-negotiable in production.
Q: How do you test non-deterministic AI?
Unit test tools as pure functions (no LLM). Integration test routing logic. E2E test structure not content — assert shape and presence, not exact words.
Q: How would you scale to 500 concurrent incidents?
Replace BackgroundTasks → Celery + Redis queue. Replace in-memory jobs → Redis. Multiple uvicorn workers. Connection pooling for ChromaDB. Cache similar incident results.
Q: Why Qwen 3B for coordinator, Gemma 4B for resolution?
Coordinator needs fast JSON planning — speed over depth. Resolution needs deep reasoning for RCA. Right model for right cognitive load. Smaller specialized = faster + cheaper.
Architecture Decision Records
ADR-1: LangGraph over pure LangChain — cycles needed for reflection retry loop. LangChain is DAG-only.
ADR-2: CrewAI + LangGraph together — LangGraph owns workflow state, CrewAI owns agent personas and task delegation.
ADR-3: Qwen 3B for fast planning, Gemma 4B for deep reasoning — cognitive load drives model selection.
ADR-4: ChromaDB over FAISS — persistent by default, metadata filtering, hybrid search, Python-native API.
ADR-5: BGE-Small over larger embeddings — CPU-optimized, near-large performance, 90MB RAM, fast inference.
